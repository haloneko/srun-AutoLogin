# 更新说明

## v1.4.0

### 新增功能

- 网络使用历史：
  - 应用运行期间按时间轴记录「什么时候连在哪个网络上」，保留最近 5 天，数据持久化
  - 新增独立的「网络使用历史」窗口：一条时间线展示所选那一天的 00:00–24:00，下方按网络汇总当天的累计时长与占比
  - 可切换查看今天 / 昨天 / 前天等日期；时间线支持滚轮缩放（最小 5 分钟、最大整天），放大后左键拖拽时间线或拖动下方滑动条即可平移
  - 时间线上可以方便区分当前网络状态
- 运行日志落盘：应用运行时把关键事件写入日志文件（单文件 5MB 自动轮转，总量恒定约 10MB，无需手动清理），排查问题不再只能看控制台
- 设置新增「打开日志目录」：一键在文件管理器中打开日志所在目录

## v1.3.0

### 新增功能

- WiFi 变动实时监听：
  - 基于 Windows WLAN API 监听网络连接变化，网络变动时自动检测最新状态并推送到界面，实时感知连上 / 断开
  - 连上校园网 WiFi 后自动探测在线状态：连接完成后延迟防抖再探测，未认证且已配置账号密码则自动登录，无需手动点击
  - 网络断开或切换到其他 WiFi 时，自动复位界面状态并给出提示，不再停留在旧状态

### 优化与重构

- 网络状态管理整体重构，界面状态显示更稳定：
  - 统一登录 / 注销 / 刷新 / 网络切换的状态流转，避免此前可能出现的状态显示异常、跳变
  - 连上校园网后的自动探测登录增加防抖与重试，网络刚连上时更容易一次成功
- 手动连接 / 注销 / 刷新走同一套稳定流程，操作响应更可靠、更及时
- 对使用无感知的内部调整：梳理网络逻辑代码结构，方便后续维护与功能扩展

### 修复

- 修复连上校园网且已在线时状态球不更新的问题（已在线始终同步状态球）
- 修复断开 WiFi 后状态球残留「已连接」的问题：断开时复位状态球。

## v1.1.1

### 新增功能

- WiFi 自动连接：
  - 设置项支持配置校园网 SSID 与密码，连接模式可选「自动」（未连接校园网时连接）/「始终」（始终连接）
  - 开机 / 静默启动时按设置自动连接校园网 WiFi，连接成功后等待网络就绪，再执行状态查询与自动登录
  - 手动点击「连接」按钮时先无条件切换至校园网 WiFi，再执行深澜登录（不受连接模式设置影响）
  - 后端基于 Windows `netsh wlan` 实现：查询当前连接、检查目标网络可用性、自动写入配置文件并连接，兼容中英文系统输出
  - 目标网络可用性检测更健壮：扫描结果为空（常见于开机自启动、WLAN 服务尚未就绪）时不再误报「未找到网络」，照常尝试连接

### 优化与重构

- 启动显示逻辑调整：用户**手动启动**应用时 100% 显示主窗口，不再受「静默启动」设置影响；仅**开机自启动**拉起时按「静默启动」设置决定是否驻留托盘（自启动项附加 `--silent` 参数以区分启动来源）
- 自启动兼容修复：老版本写入的自启动项未带 `--silent` 参数，升级后自启动会误弹主窗口。现改为在应用启动时对比上次记录的应用版本号，版本不一致则复用自启动插件重写一遍启动项（自动补齐参数）；版本号随普通数据一并记录，无需用户手动关闭再开启自启动

## v1.1.0

### 新增功能

- 设置项全面扩展，支持适配其他学校网关：
  - 高级设置支持自定义认证组 ID、加密版本（主题三选：跟随系统 / 浅色 / 深色）
  - 加密字母表独立到高级设置，支持自定义深澜 Base64 字母表
  - 支持自定义 User-Agent（留空使用默认），登录 / 状态 / 注销请求均生效
  - 服务器地址 / 认证组 ID / 加密版本 / 加密字母表留空即使用默认值，校验与提示同步调整
- 新增静默启动开关（默认开启）：开机静默启动后仅驻留系统托盘，不显示主界面；主窗口改为默认隐藏，由前端按设置显示
