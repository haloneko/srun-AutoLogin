# 更新说明

## v1.1.1

### 新增功能

- WiFi 自动连接：
  - 设置项支持配置校园网 SSID 与密码，连接模式可选「自动」（未连接校园网时连接）/「始终」（始终连接）
  - 开机 / 静默启动时按设置自动连接校园网 WiFi，连接成功后等待网络就绪，再执行状态查询与自动登录
  - 手动点击「连接」按钮时先无条件切换至校园网 WiFi，再执行深澜登录（不受连接模式设置影响）
  - 后端基于 Windows `netsh wlan` 实现：查询当前连接、检查目标网络可用性、自动写入配置文件并连接，兼容中英文系统输出
  - 目标网络可用性检测更健壮：扫描结果为空（常见于开机自启动、WLAN 服务尚未就绪）时不再误报「未找到网络」，照常尝试连接

### 优化与重构

- 启动显示逻辑调整：用户**手动启动**应用时 100% 显示主窗口，不再受「静默启动」设置影响；仅**开机自启动**拉起时按「静默启动」设置决定是否驻留托盘（自启动项附加 `--silent` 参数以区分启动来源）
- 自启动兼容修复：老版本写入的自启动项未带 `--silent` 参数，升级后自启动会误弹主窗口。现改为在应用启动时对比上次记录的应用版本号，版本不一致则复用自启动插件重写一遍启动项（自动补齐参数）；版本号随普通数据一并记录，无需用户手动关闭再开启自启动

## v1.1.0

### 新增功能

- 设置项全面扩展，支持适配其他学校网关：
  - 高级设置支持自定义认证组 ID、加密版本（主题三选：跟随系统 / 浅色 / 深色）
  - 加密字母表独立到高级设置，支持自定义深澜 Base64 字母表
  - 支持自定义 User-Agent（留空使用默认），登录 / 状态 / 注销请求均生效
  - 服务器地址 / 认证组 ID / 加密版本 / 加密字母表留空即使用默认值，校验与提示同步调整
- 新增静默启动开关（默认开启）：开机静默启动后仅驻留系统托盘，不显示主界面；主窗口改为默认隐藏，由前端按设置显示
